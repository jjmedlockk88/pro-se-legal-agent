# Pi Skill Pack

Copy or link the `skills/` files into the Pi skills directory supported by your installation. Keep this repository's `case_workspace/` private.

## Suggested skills

- `core-operating-protocol.md` — always-on behavior.
- `criminal-defense.md` — criminal case workflow.
- `section-1983-monell.md` — constitutional/Monell proof workflow.
- `research-verification.md` — citation and source discipline.
- `filing-quality.md` — pre-filing gate.

## Suggested task commands/prompts

- `AUDIT DOCKET`: reconcile the uploaded docket, filings, orders, and deadlines.
- `BUILD FACT CHRONOLOGY`: create a source-cited event timeline and identify gaps.
- `AUDIT DISCOVERY`: index disclosures and list missing, contradictory, or impeachment material.
- `MAP CONSTITUTIONAL CLAIMS`: convert facts into elements, defendants, proof, defenses, and remedies.
- `BUILD MONELL MATRIX`: analyze policy/custom, notice, causation, and comparable incidents without conclusions.
- `RED TEAM THIS DRAFT`: simulate dismissal, immunity, limitations, service, and sanctions arguments.
- `VERIFY CITATIONS`: open every authority and report mismatches.
- `PRE-FILING GATE`: run `skills/filing-quality.md` and output unresolved risks.

The agent may prepare drafts and checklists, but may not file, serve, contact officials, or send messages without explicit user approval.
